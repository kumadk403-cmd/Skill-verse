# SkillVerse — Improve Your Skills

A responsive, animated, beginner-friendly learning website.

## Features
- Five learning paths: web development, graphic design, video editing, 3D CAD, and freelancing/career.
- Search and category filters.
- Interactive checklists and progress dashboard.
- Progress saved locally in the browser with localStorage.
- External free learning resources.
- Mobile-friendly design and animated hero section.

## Run
Open `index.html` in a modern browser. No build tools required.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `app.js`, and `README.md`.
3. Go to Settings → Pages.
4. Select the main branch and root folder, then save.

Progress is stored on the current device/browser and does not sync across devices. External links need internet access.
